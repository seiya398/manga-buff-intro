PROBLEM

作家さんが抱える
3つの悩み、ありませんか？

個人で商業電子書店に挑戦しようとすると、多くの作家さんが同じ壁にぶつかります。

PROBLEM 01

電子書店ごとの
交渉が大変

書店ごとに審査・入稿仕様・書誌テンプレートが異なり、個人で全書店を回るのは実質不可能。

PROBLEM 02

FANZA同人だけでは
頭打ち

同人プラットフォームだけでは読者層が限定される。商業書店に展開して新規読者を獲得したい。

PROBLEM 03

従来の取次は
還元率が低い

取次とは、出版社や作者に代わって、電子書店へ作品を届ける会社（またはその仕組み）のこと。業界標準の取次では作家還元が40%前後で、結局自分の手元にいくら残るのかが見えにくい。

SOLUTION

MANGA BUFFなら、全部解決。

作家さんは本編データと作品情報を渡すだけ。残りはすべてお任せください。

🛠

全部代行

書店交渉・EPUB制作・書誌入力・表紙デザインまで対応。作家さんの手間はゼロ。

🏪

100書店へ一括

コミックシーモア・楽天Kobo等の主要書店を含む100以上の書店へ（全年齢含む総数）。成人向けAIは約30書店ですが、売れる店は押さえています。

💰

手取りは売価の約20%

本使用料に対する還元率は60%で、業界水準（40%前後）の約1.5倍。手取りは販売価格の約20%が目安です。

🎨

AI作品も公式対応

AI生成作品も対応。「AI使用あり」と申告いただければ、当社が出せる書店を選定して配信します。お預かりの条件は下記をご覧ください。
