PROBLEM

作家さんが抱える
3つの悩み、ありませんか？

個人で商業電子書店に挑戦しようとすると、多くの作家さんが同じ壁にぶつかります。

PROBLEM 01

電子書店ごとの
交渉が大変

書店ごとに審査・入稿仕様・書誌テンプレートが異なり、個人で全書店を回るのは実質不可能。

PROBLEM 02

FANZA同人だけでは
頭打ち

同人プラットフォームだけでは読者層が限定される。商業書店に展開して新規読者を獲得したい。

PROBLEM 03

従来の取次は
還元率が低い

業界標準の取次では作家還元が40%前後。結局自分の手元にいくら残るのかが見えにくい。

SOLUTION

MANGA BUFFなら、全部解決。

作家さんは本編データと作品情報を渡すだけ。残りはすべてお任せください。
