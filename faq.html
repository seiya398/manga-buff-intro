💰 お金関連

還元率60%は販売額の60%ですか？
いいえ。還元率は「電子書店の手数料を引いた後、MANGA BUFF に入ってくるお金」に対する割合です。書店手数料は書店ごとに異なる（おおむね50〜70%）ため、最終的に作家さんの手取りになるのは販売金額の20%前後とお考えください。手数料の低い書店ではもっと高くなります。業界水準の取次と比べると手取りは約1.5倍です。
結局、いくらくらい還元されますか？（実際の数字）
実際に配信している作品の集計値では、1作品の配信開始30日の売上は中央値で約5.5万円（作家還元の目安 約1万円/作品）。複数作品を預けている作家さんの月間還元は、中央値 約2万円/月（およそ4作品を預けた場合）、上位25%の方で月5.7万円〜、いちばん多い方で月47万円ほどです。作品を積むほど比例して伸びます。詳しくは 料金・お金のページ へ。
初回の振込はいつごろですか？
配信開始から約6ヶ月後が目安です。5月に配信開始すると、5〜7月分の売上が11月末に振込されます。その後は3ヶ月ごとに定期的に振込。なお主力書店のコミックシーモアは販売月から3ヶ月遅れで報告・支払いされるため、その分はさらに後ろ倒しになります。
なぜ支払いが4ヶ月後なんですか？
業界構造上の理由です。① 書店から取次への報告に1〜2ヶ月、② コミックシーモアは3ヶ月遅れ報告、③ 全書店の数字が揃わないと正確な金額で振込できない。業界標準（年4回・120日サイト等）と同等のサイクルです。
売上明細は見られますか？
還元金の振込月の前月に、書店別の内訳をスプレッドシートで開示します（電子書店名は開示可能な書店に限ります）。加えて月末に売上の速報値も共有。「今どうなってるか分からない」という状態にはしません。
源泉徴収はどうなりますか？
個人口座宛のお振込みの場合、所得税法に基づき10.21%の源泉徴収を差し引いてお支払いします。法人口座宛は源泉徴収不要です。
インボイス未登録でも大丈夫ですか？
はい、未登録でも契約・配信は可能です。ただし適格請求書発行事業者の登録が無い場合、消費税の仕入税額控除の都合上、消費税相当分の一部を差し引かせていただきます（現在は経過措置により段階的に変動）。登録済みの場合はこの控除はありません。
表紙を作ってもらって売れなかったら、費用を請求されますか？
いいえ、一切請求しません。表紙制作・EPUB化・モザイク処理などはすべて当社負担で行い、売れなかった場合でも費用をお願いすることはありません。完全成果報酬型なので、預けて赤字になるリスクはゼロです。
確定申告はどうなりますか？支払調書は出ますか？
確定申告は作家さんご自身で行っていただきます。年間の還元金額・源泉徴収額は支払通知書でお知らせしますので、そのまま申告にお使いいただけます（こちらへの請求書発行も不要です）。

📝 契約関連

契約書を先に見せてもらえますか？
はい。契約について のページで契約書の全文を公開しています。条文ごとの解説とあわせて、締結前にじっくりお読みいただけます。
他の取次と契約していても、MANGA BUFF と契約できますか？
はい。MANGA BUFF は作品単位の独占なので、お預けいただく作品が他取次で配信中（または配信契約中）でなければ問題ありません。作品Aは他社取次、作品Bは MANGA BUFF、といった使い分けも可能です。
1年間縛られるのが不安です
契約期間は1年ですが、配信開始後に「合わない」と感じた場合、3ヶ月前通告で1年経過後に離脱可能です。実質的に「試しに1作品預けてみる」という使い方もできます。
解約したら、配信中の作品はどうなりますか？
解約しても、すでに配信中の作品は「配信開始から1年（最低配信期間）」はそのまま配信が続き、その間も還元率60%等の条件は変わりません。最低配信期間を過ぎた作品は配信を終了します（契約終了後おおむね2ヶ月で配信終了）。入稿データは終了後にご要望いただければ合理的な範囲で削除します。
FANZA専売（独占販売）中の作品も預けられますか？
預けられます。ただしFANZA同人で「専売」に設定している作品は他書店に配信できないため、専売設定を外していただく必要があります。外す際は対象作品をまとめてFANZAへ一括で問い合わせるのが安全です。手順が不安な場合はサポートします。
価格は自分で決められますか？勝手に値下げされませんか？
ご希望価格を最大限尊重し、市場水準と大きくずれていなければ基本はご希望どおりで配信します。無断で安売りすることはありません。契約書上の最終決定権を当社が持つのは、極端な安売りで市場が崩れるのを防ぐためです。詳しくは 契約について へ。

🎨 作品関連

作品データの形式は？どう渡せばいいですか？
CLIP STUDIO形式、PSD、JPG、PDF いずれにも対応。お手元の形式のままでOKです。契約後、Discordの専用チャンネルや大容量便で受け取ります。詳しくは サービス内容・納品方法 のページへ。
成人向けでも大丈夫ですか？
成人向け作品を主力として取り扱っています。モザイク処理・白抜き対応等のノウハウもございます。追加費用はかかりません。
AI生成作品も扱えますか？絵柄が他の作家に似ていたら？
はい、AI作品は当社の主力です。「AI使用あり」とお知らせいただければ、出せる書店を選定して配信します。絵柄が特定の作家・キャラに酷似していそうな場合は、配信前のチェック（AI＋目視＋書店審査の三段構え）でお知らせし、必要なら該当作品を外すご提案をします。
具体的にどの電子書店に配信されますか？成人向けはどこに出ますか？
成人向け作品が実際に乗る代表例は、コミックシーモア／楽天Kobo／ブックライブ／DMMブックス／DLsite／FANZA／Renta!／ebookjapan／BOOK☆WALKER／honto など。全年齢作品ならさらに幅広く配信できます。「この書店には出したくない」という除外指定も可能です。なお成人向けAI漫画では実際に配信できるのは30書店ほどです（配信先一覧）。Amazon（Kindle）はAI成人作品がガイドライン抵触で配信停止になった例があります。
二次創作も扱えますか？
残念ながら二次創作は権利関係の都合で取り扱いが困難です。一次創作作品のみお預かり可能です。
総集編・おまけコンテンツは？CG集は？
総集編は個別相談で対応可。おまけ単独は基本不可（本編組み込みならOK）。純粋なCG集・写真集は取次対象外で、漫画作品（混合含む）が対象です。電子書店は「1作品＝1商品」の単位で販売する構造のためです。

🛠 運用・その他

資料を見たあと、どう進みますか？
ご相談・お申し込み → X DMでのご案内 → Discord招待 → 契約書送付 → 電子署名 → 作品お預かり → 配信準備 → 配信開始 → 売上共有 → 振込、という流れです。ご相談後の流れ のページでステップごとに説明しています。
弊社が制作した表紙・白抜き素材のデータはもらえますか？
弊社が配信用に新規制作した表紙・加工データは、配信用途に限定した制作物のため、原則としてデータのお渡しはしておりません（著作権は弊社帰属・SNSや広告での使用は対象外）。作家さんがご自身でFANZA・DLsite等で販売している版は、今の表紙のまま継続いただけます。詳しくは 契約について へ。
表紙制作も依頼できますか？
はい、ご依頼可能です。追加費用なし（業務委託料の40%に含まれます）。キャラクター素材をいただければ、書店規格に合わせて弊社で制作します。
契約後の連絡はどうやって行いますか？
契約後の作品のやり取り・進捗共有は、作家さんごとのDiscord専用チャンネルで行います。連絡・レスポンスが速いのが強みです。
商標・著作権チェック漏れの責任は？
「AIチェック＋目視チェック」の二段階に加え、書店側の審査も入るため実質三段構えで確認しています。万が一問題が発覚した場合は即座に配信停止と修正対応を行います。ただし最終的な法的責任は権利保有者である作家さんに帰属します（業界標準のルール）。作家さんご自身でも一度チェックいただくことを推奨しています。
個人で出した方が取り分が多いのでは？
個人だと全書店の審査・入稿・モザイク・売上集計をすべて自分でやり続ける必要があります。その時間を制作に回せて、なおかつ手取りも残る設計です。「手間を引いた後に残る額」で比べてみてください。
