💰 お金関連

還元率60%は販売額の60%ですか？
いいえ。還元率は「電子書店の手数料を引いた後、MANGA BUFF に入ってくるお金」に対する割合です。書店手数料は書店ごとに異なる（おおむね50〜70%）ため、最終的に作家さんの手取りになるのは販売金額の20%前後とお考えください。手数料の低い書店ではもっと高くなります。業界水準の取次と比べると手取りは約1.5倍です。
結局、いくらくらい還元されますか？（実際の数字）
実際に配信している作品・作家さんの集計値（1作品の初動30日、作品数別の月間の手取り、累計の手取り）は 手取りと支払いのページ に掲載しています（毎月自動で更新されるため、最新の数字はそちらをご覧ください）。作品を積むほど手取りは積み上がります。
「還元率80%」の他社の方が得ではないですか？
率だけ見ればそう見えますし、正直に言えば80%のサービスもあります。ただ80%還元は、表紙制作・モザイク・話数分割・書誌入力・書店ごとの運用をすべて作家さんご自身で行う前提です。MANGA BUFF の60%はそれらを全部こちらで巻き取ったうえでの数字なので、手間・配信できる書店数・伴走を含めた「手取りと手数」で比べてみてください。詳しくは 比較表 へ。
初回の振込はいつごろですか？
配信開始から約6ヶ月後が目安です。5月に配信開始すると、5〜7月分の売上が11月末に振込されます。その後は3ヶ月ごと（年4回）に定期的に振込。なお主力書店のコミックシーモアは販売月から3ヶ月遅れで報告・支払いされるため、その分はさらに後ろ倒しになります。「しばらく入金がない」のは異常ではなく、この仕組みによるものです。
なぜ入金まで時間がかかるのですか？
業界構造上の理由です。① 書店から取次への報告に1〜2ヶ月、② コミックシーモアは3ヶ月遅れ報告、③ 全書店の数字が揃わないと正確な金額で振込できない。契約書上は「各期間（3ヶ月ごと）の締め日から4ヶ月後の末日に振込」で、年4回の精算サイクル自体は業界標準です。一部の書店では、書店から当社への入金までにさらに日数がかかります。結果として初回は配信開始から約6ヶ月後が目安になります。
売上は教えてもらえますか？どこで報告されますか？
売上は総額をお伝えします。ストア別・書店別の内訳は開示していません。月末に速報、振込の前月に確定額を通知。報告は契約後の Discord 連絡用スレッドで行います。「今どうなってるか分からない」という状態にはしません。
振込口座で気をつけることは？
契約時にお知らせいただく口座の名義（カナ）が、通帳やアプリの表記と一致しているかご確認ください。名義が一致しないと振込が戻ってしまい、お支払いが次回以降に遅れます。
契約が終わるとき・途中で解約するときの精算はどうなりますか？会社が事業をやめたら？
契約終了までに発生した売上分は、契約終了後1ヶ月以内に精算してお支払いします。当社が事業を停止する場合も同様に、停止後1ヶ月以内に精算します。なお解約後も、配信開始から1年（最低配信期間）の作品は配信が続き、その間の売上は通常どおり3ヶ月ごとに精算します（契約書第15条4項）。
源泉徴収はどうなりますか？
個人口座宛のお振込みの場合、所得税法に基づき10.21%の源泉徴収を差し引いてお支払いします。法人口座宛は源泉徴収不要です。
インボイス未登録でも大丈夫ですか？
はい、未登録でも契約・配信は可能です。ただし適格請求書発行事業者の登録が無い場合、消費税の仕入税額控除の都合上、消費税相当分の一部を差し引かせていただきます（現在は経過措置により段階的に変動）。登録済みの場合はこの控除はありません。
表紙を作ってもらって売れなかったら、費用を請求されますか？
いいえ、一切請求しません。表紙制作・EPUB化・モザイク処理などはすべて当社負担で行い、売れなかった場合でも費用をお願いすることはありません。完全成果報酬型なので、預けて赤字になるリスクはゼロです。
確定申告はどうなりますか？支払調書は出ますか？
確定申告は作家さんご自身で行っていただきます。年間の還元金額・源泉徴収額は支払通知書でお知らせしますので、そのまま申告にお使いいただけます（こちらへの請求書発行も不要です）。

📝 契約関連

契約書を先に見せてもらえますか？
はい。契約について のページで契約書の全文を公開しています。条文ごとの解説とあわせて、締結前にじっくりお読みいただけます。
他の取次と契約していても、MANGA BUFF と契約できますか？
はい。MANGA BUFF は作品単位の独占なので、お預けいただく作品が他取次で配信中（または配信契約中）でなければ問題ありません。作品Aは他社取次、作品Bは MANGA BUFF、といった使い分けも可能です。
なぜ1年契約なのですか？縛られるのが不安です
表紙制作・電子化・入稿などの費用を当社が先に負担する（売れなくても作家さんの負担はゼロ）ため、回収の期間として1年をいただいています。1年経過後は3ヶ月前通告で解約でき、実質最短13ヶ月です。5年縛りのような長期の拘束はありません。
契約書の料率が、説明会やメッセージで聞いた料率と違います
署名する前に、必ずご連絡ください。一致させた契約書を送り直してから署名していただきます。署名後の訂正はお互いに手間がかかるので、違和感があればそのままにしないでください。
「取次独占」（契約書第11条）では、何が制限されるのですか？
制限されるのは「預けた作品を、ほかの取次を通して電子書店に出すこと」と「預けた作品と同じ内容を、同じ書店に重ねて出すこと」の2つだけです。FANZA同人・DLsite・BOOTH などの同人プラットフォーム、Kindle等のセルフパブ、預けていない別作品の他社委託は自由です。詳しくは 契約について へ。
マネーフォワードの電子署名のやり方が分かりません／署名が遅れそうです
そのままにせず、専用窓口かメールでご連絡ください。手順をご案内します。契約書のメールが見当たらない場合（迷惑メールに入ることがあります）もお知らせください。再送します。
本名を出さずに契約できますか？
本名を書くのは契約書（と振込口座）だけです。予約・説明会・Discord はペンネーム／サークル名で構いません。本名を社外へ出すことはありません。
海外在住でも契約できますか？
現状では、海外在住の方とはご契約いただけません（国内の銀行口座への振込・国内での源泉徴収を前提としているため）。
解約したら、配信中の作品はどうなりますか？
解約しても、すでに配信中の作品は「配信開始から1年（最低配信期間）」はそのまま配信が続き、その間も還元率60%等の条件は変わりません。最低配信期間を過ぎた作品は配信を終了します（契約終了後おおむね2ヶ月で配信終了）。入稿データは終了後にご要望いただければ合理的な範囲で削除します。
FANZA専売（独占販売）中の作品も預けられますか？
預けられます。ただしFANZA同人で「専売」に設定している作品は他書店に配信できないため、専売設定を外していただく必要があります。外す際は対象作品をまとめてFANZAへ一括で問い合わせるのが安全です。手順が不安な場合はサポートします。
価格は自分で決められますか？勝手に値下げされませんか？
販売価格は当社が決定します（ご希望はうかがいます）。相場の目安はページ数×10円（例：90ページなら約900円）で、レンタル価格も同じ考え方です。無断で極端な安売りをすることはありません。値引きが入るのは主に書店主催セールなどで、割引50%以上・無料キャンペーンは必ず事前に確認します。詳しくは 契約について と 売れ方と企画 へ。

🎨 作品関連

作品データの形式は？どう渡せばいいですか？
CLIP STUDIO（.clip）、PSD、JPG、PNG、PDF いずれにも対応。お手元の形式のままでOKで、JPGをページ順にZIPにまとめていただく形で十分です。契約後、Discordの専用チャンネル・大容量便・Googleドライブの共有フォルダ（作品素材共有用）のいずれかで受け取ります。詳しくは サービス内容・納品方法 のページへ。
奥付に載せるSNSのIDは、あとから変えられますか？
奥付に記載した X のIDは、配信後に変更できません。長く使う予定のIDをお知らせください。記載は任意です。
書影（表紙まわりの画像）は自分で用意する必要がありますか？
いいえ。表紙そのものも、書店に並ぶ書影（書誌画像）も運営が制作します。キャラクター素材をいただければ十分です。
成人向けでも大丈夫ですか？
成人向け作品を主力として取り扱っています。モザイク処理・白抜き対応等のノウハウもございます。追加費用はかかりません。
AI生成作品も扱えますか？絵柄が他の作家に似ていたら？
はい、AI作品は当社の主力です。「AI使用あり」とお知らせいただければ、当社が出せる書店を選定して配信します（書店への申告手続きは当社が行います）。絵柄が特定の作家・キャラに酷似していそうな場合は、配信前のチェック（AI＋目視＋書店審査の三段構え）でお知らせし、必要なら該当作品を外すご提案をします。
AIで量産した未公開作品を、まとめて預けられますか？
お預かりするのは、①すでに同人として公開済みの作品を商業配信に乗せる場合、または②商業配信専用として制作する作品のどちらかです。量産した未公開のストックをそのまま大量にお預けいただく形はお受けしていません。一作ずつ読者に届く形で一緒に出していければと思っています。詳しくは AI作品のお預かり条件 へ。
全年齢のAI作品も預けられますか？
事前確認のうえお預かりできます。サンプルをお見せいただく条件があります。条件の細部はご相談時に個別にご案内します。
具体的にどの電子書店に配信されますか？成人向けはどこに出ますか？
成人向け作品が実際に乗る代表例は、コミックシーモア／DMMブックス／FANZA Books／DLsite（商業フロア）／楽天Kobo／ブックライブ／Renta!／ebookjapan／BOOK☆WALKER／honto／auブックパス／dブック など。全年齢作品ならさらに幅広く配信できます。なお成人向けAI漫画では実際に配信できるのは30書店ほどです（配信先一覧）。ただし売れる書店はだいたい決まっていて、売れる店は押さえています。Amazon（Kindle）はAI成人作品がガイドライン抵触で配信停止になった例があり、成人向けAIでは落ちやすい書店です。なお配信先書店の選定は当社が行い（契約書第1条5項）、作家側で自由に指定・除外することはできません。最終的な配信可否は各書店の審査によります。
預ける前に、配信先の全書店リストをもらえますか？
成人向けの代表店は サービス内容 に掲載しています。全配信先の一覧については、ご相談時に個別にご案内します。
契約から配信開始まで、どれくらいかかりますか？
データをお預かりしてから配信準備に約1〜2週間、その後は書店ごとに審査が通った順に配信が始まります。書店ごとに審査期間が異なるため、全書店の一斉公開日や、契約から初公開までの総日数はお約束できません。
自分の作品が本当に公開されているか、どう確認すればいいですか？
配信が始まったら運営から専用窓口でご連絡します。あわせて、ご自身でも書店で作品名を検索して確認してください。日が経っても見当たらない、連絡が来ない、という場合はすぐにお知らせください。すぐに状況を確認します。
自分で同人として売り続けながら、取次版も出せますか？FANZA同人とFANZA Booksの重複は？
同人プラットフォームでの直接販売は自由で、同人版と商業版は併存できます（読者層が違うため売り場が純増します。おすすめは同人で1〜2ヶ月先行→商業展開）。ただし、同人版と商業版が同じ運営会社の書店になる場合（例：FANZA同人と FANZA Books）は、同人側の取り下げや専売解除が必要になることがあります。該当しそうな作品はお預かり前に一緒に確認します。詳細（同人版と商業版の価格差・改訂版の扱いを含む）は、ご相談時に個別にご案内します。
話売りと巻売り、どちらで出ますか？段階的に出せますか？
40ページ以上の作品は10ページ＝1話などの話数売りにすることがあり、巻売り（単行本）と組み合わせることもあります。分け方は当社が設計し、事前にご相談します。実売の傾向として総集編より単行本が売れています。段階的な出し方や細かいルールは、ご相談時に個別にご案内します。
Kindle Unlimited（読み放題）には入りますか？
Kindle Unlimited（読み放題）については、ご相談時に個別にご案内します。なお Amazon（Kindle）は成人向けAI作品が落ちやすい書店です。
海外・英語版はどうなりますか？他社に英語版を独占許諾済みの作品は預けられますか？
海外書店・英語版、および他社へ英語版を独占許諾済みの作品の日本語版については、ご相談時に個別にご案内します。
広告は出してもらえますか？費用は？
書店のセール・特集・レコメンド枠への掲載は当社が調整します。当社や書店が出す広告については、ご相談時に個別にご案内します。作家さんに広告費をご負担いただくことはありません。
二次創作も扱えますか？
残念ながら二次創作は権利関係の都合で取り扱いが困難です。一次創作作品のみお預かり可能です。
総集編・おまけコンテンツは？CG集は？
総集編は個別相談で対応可（実売の傾向としては総集編より単行本が売れています）。おまけ単独は基本不可（本編組み込みならOK）。純粋なCG集・写真集は取次対象外で、漫画作品（混合含む）が対象です。電子書店は「1作品＝1商品」の単位で販売する構造のためです。
タイトルや価格、出し方は相談できますか？
はい。タイトル・価格・話売りか巻売りかなどの出し方は、お預かりの前に運営とご相談いただけます。書店の審査に合わせてタイトルの一部伏せ字などの編集が入ることがあります。売れ方の傾向は 売れ方と企画 にまとめています。

🛠 運用・その他

資料を見たあと、どう進みますか？
ご相談・お申し込み → Discord IDを共有 → Discord招待 → 契約書送付 → 電子署名 → 作品お預かり → 配信準備 → 配信開始 → 売上共有 → 振込、という流れです。ご相談後の流れ のページでステップごとに説明しています。
弊社が制作した表紙・白抜き素材のデータはもらえますか？
弊社が配信用に新規制作した表紙・加工データは、配信用途に限定した制作物のため、原則としてデータのお渡しはしておりません（著作権は弊社帰属・SNSや広告での使用は対象外）。作家さんがご自身でFANZA・DLsite等で販売している版は、今の表紙のまま継続いただけます。詳しくは 契約について へ。
表紙制作も依頼できますか？
はい、ご依頼可能です。追加費用なし（本使用料のうち当社が制作・配信業務に使う40%に含まれます）。キャラクター素材をいただければ、書店規格に合わせて弊社で制作します。
契約後の連絡はどうやって行いますか？
契約後の作品のやり取り・進捗共有は、作家さんごとのDiscord専用窓口で行います。売上の報告は連絡用チャンネル内のスレッドで行います。連絡・レスポンスが速いのが強みです。
Discordが使えません。ほかの方法はありますか？
メール＋Googleドライブ（作品素材共有用フォルダ）でのやり取りに切り替えられます。ご相談時にお知らせください。
商標・著作権チェック漏れの責任は？
「AIチェック＋目視チェック」の二段階に加え、書店側の審査も入るため実質三段構えで確認しています。万が一問題が発覚した場合は即座に配信停止と修正対応を行います。ただし最終的な法的責任は権利保有者である作家さんに帰属します（業界標準のルール）。作家さんご自身でも一度チェックいただくことを推奨しています。
個人で出した方が取り分が多いのでは？
個人だと全書店の審査・入稿・モザイク・売上集計をすべて自分でやり続ける必要があります。その時間を制作に回せて、なおかつ手取りも残る設計です。「手間を引いた後に残る額」で比べてみてください。

🗓 説明会・会社について

説明会はカメラなし・音声だけでも参加できますか？
はい。カメラ・マイクなし、音声のみ、テキスト中心のどれでも参加できます。オンラインが難しい方には、テキストでの質疑応答でお答えします。
予約や説明会で本名を名乗る必要がありますか？
いいえ。予約・説明会はペンネーム／サークル名で構いません。本名を書くのは契約書だけで、社外へ出すことはありません。
どんな会社が運営していますか？実在する会社ですか？
運営は合同会社Realize（代表：竹内星陽）です。所在地は契約書の末尾に記載のとおり（東京都渋谷区）。会社サイト、代表のnote、この資料の 代表とMANGA BUFF のページで、どんな人がやっているかをご確認いただけます。
